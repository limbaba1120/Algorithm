# 명예의 전당 (1)

- 문제 번호: 138477
- 난이도: Level 1
- 풀이 날짜: 2026-07-26
- 핵심 자료구조: 최소 힙(`PriorityQueue`)
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/138477

## 핵심 아이디어

- 매일 새 점수를 명예의 전당에 넣는다.
- 점수가 `k`개를 넘으면 가장 낮은 점수를 뺀다.
- 남아 있는 점수 중 최솟값이 그날의 발표 점수다.

명예의 전당에는 가장 높은 점수 `k`개만 남겨야 한다. 따라서 새 점수를 넣을 때마다 전체를 정렬할 필요 없이, 가장 낮은 점수만 빠르게 찾을 수 있는 최소 힙을 사용한다.

## 최소 힙 그림

```text
명예의 전당 점수: 100, 80, 70

        70  ← peek(): 현재 최하위 점수
       /  \
     100   80
```

최소 힙은 가장 작은 값을 맨 위에 둔다. 전체가 정렬된 것은 아니지만 최솟값은 바로 확인할 수 있다.

## 사용한 기능

```java
hallOfFame.offer(score); // 점수 추가
hallOfFame.poll();       // 최솟값 제거
hallOfFame.peek();       // 최솟값 확인
```

- `offer()`는 새 점수를 힙에 넣는다.
- `poll()`은 가장 작은 점수를 반환하면서 제거한다.
- `peek()`은 가장 작은 점수를 제거하지 않고 확인한다.

`PriorityQueue<Integer>`는 기본적으로 최소 힙이다. 따라서 별도의 정렬 기준을 전달하지 않아도 가장 낮은 점수가 앞에 온다.

## 흐름

```text
새 점수 추가
    ↓
k개를 초과했는가?
 ├─ 예 → 최솟값 제거
 └─ 아니요
    ↓
현재 최솟값 기록
```

## 간단한 예시

`k = 3`, 점수가 `10, 100, 20, 150` 순서로 들어온다고 생각해 보자.

```text
1일: [10]           → 발표 점수 10
2일: [10, 100]      → 발표 점수 10
3일: [10, 20, 100]  → 발표 점수 10
4일: 150 추가
     [10, 20, 100, 150]
     k개 초과 → 10 제거
     [20, 100, 150]  → 발표 점수 20
```

초반에는 등록된 점수가 `k`개보다 적더라도, 현재 등록된 점수 중 가장 낮은 점수를 발표한다.

## 주의할 점

- `answer`의 크기는 `score.length`로 만든다.
- 점수를 먼저 추가한 다음, 크기가 `k`를 초과했는지 확인한다.
- 이 문제에서는 가장 낮은 점수를 제거해야 하므로 최대 힙이 아니라 최소 힙을 사용한다.
- `PriorityQueue`를 출력했을 때 배열 전체가 정렬되어 보인다는 보장은 없다. `peek()`으로 확인하는 최솟값만 보장된다.

## 복잡도

- 점수 추가와 제거: 각각 `O(log k)`
- 최솟값 확인: `O(1)`
- 전체 시간: `O(n log k)`
- 공간: `O(k)`
