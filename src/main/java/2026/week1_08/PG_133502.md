# 햄버거 만들기

- 문제 번호: 133502
- 난이도: Level 1
- 핵심 자료구조: `ArrayDeque`
- 핵심 알고리즘: 스택, 구현
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/133502

## 문제와 접근 방법

재료가 주어진 순서대로 쌓일 때 `빵(1) → 야채(2) → 고기(3) → 빵(1)`이 만들어지면 햄버거 하나를 포장하고 사용한 재료 네 개를 제거한다. 제거 후 기존 재료들이 다시 이어질 수 있으므로 마지막에 들어온 값을 먼저 확인하고 제거하는 스택 방식이 적합하다.

```text
재료: 2 1 1 2 3 1 2 3 1

2 1 [1 2 3 1] 2 3 1  →  2 1 2 3 1
2 [1 2 3 1]           →  2

결과: 햄버거 2개
```

## `ArrayDeque`를 스택으로 사용하기

```java
Deque<Integer> deque = new ArrayDeque<>();
```

`Deque`는 양쪽 끝에서 값을 넣고 뺄 수 있는 인터페이스이고, `ArrayDeque`는 이를 배열 기반으로 구현한 클래스다.

| 용도 | 추가 | 제거 | 확인 |
|---|---|---|---|
| 스택 | `push()` | `pop()` | `peek()` |
| 큐 | `offer()` | `poll()` | `peek()` |

```java
push(value)  == addFirst(value)
pop()        == removeFirst()
offer(value) == offerLast(value)
poll()       == pollFirst()
```

- `pop()`: 앞의 값을 제거하고 반환하며, 비어 있으면 예외가 발생한다.
- `poll()`: 앞의 값을 제거하고 반환하며, 비어 있으면 `null`을 반환한다.
- `pushFirst()`와 `popFirst()`라는 메서드는 없다. 앞쪽을 명시하려면 `offerFirst()`, `pollFirst()`, `removeFirst()` 등을 사용한다.
- `ArrayDeque`에는 `get(index)`가 없다.

## 재료 순서가 반대로 보이는 이유

`push()`는 새 값을 덱의 앞에 넣는다. 재료 `1, 2, 3, 1`을 차례로 넣으면 다음과 같이 저장된다.

```text
push(1) → [1]
push(2) → [2, 1]
push(3) → [3, 2, 1]
push(1) → [1, 3, 2, 1]
           ↑ 덱의 앞
```

따라서 덱의 앞에서부터 `1, 3, 2, 1`인지 확인해야 한다.

## `Iterator`로 재료 확인하기

`Iterator`는 컬렉션의 값을 제거하지 않고 하나씩 순서대로 확인하는 객체다.

```java
Iterator<Integer> iterator = deque.iterator();

iterator.hasNext(); // 다음 값이 있는지 확인
iterator.next();    // 다음 값을 반환하고 한 칸 이동
iterator.remove();  // 가장 최근에 반환한 값을 제거
```

덱이 `[1, 3, 2, 1]`이라면 `next()`의 결과는 차례대로 `1`, `3`, `2`, `1`이다. 네 번 안전하게 호출할 수 있도록 먼저 크기를 확인한다.

```java
if (deque.size() >= 4) {
    Iterator<Integer> iterator = deque.iterator();

    if (iterator.next() == 1
            && iterator.next() == 3
            && iterator.next() == 2
            && iterator.next() == 1) {
        deque.pop();
        deque.pop();
        deque.pop();
        deque.pop();
        answer++;
    }
}
```

`&&`는 앞 조건이 거짓이면 뒤 조건을 실행하지 않는 단락 평가를 한다. 다음 재료를 처리할 때 새로운 반복자를 만들기 때문에 일부 `next()`가 실행되지 않아도 문제가 없다.

`iterator()`는 앞에서 뒤로, `descendingIterator()`는 뒤에서 앞으로 순회한다.

## `Iterator`와 컬렉션

`List`, `Set`, `Queue`, `Deque` 등 `Collection` 계열은 `iterator()`로 모든 요소를 순회할 수 있다.

```java
Iterator<Integer> iterator = collection.iterator();

while (iterator.hasNext()) {
    int value = iterator.next();
}
```

향상된 `for`문도 내부적으로 반복자를 사용하는 것과 비슷하다.

```java
for (int value : collection) {
    System.out.println(value);
}
```

`Map`은 `Collection`이 아니므로 직접 `iterator()`를 호출할 수 없다. `keySet()`, `values()`, `entrySet()` 중 하나를 통해 순회해야 한다.

```java
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey());
    System.out.println(entry.getValue());
}
```

모든 값을 순회할 수 있다는 것과 순서가 보장된다는 것은 별개다. `ArrayList`와 `ArrayDeque`는 정해진 순서로 순회하지만, `HashSet`과 `HashMap`은 순회 순서를 보장하지 않는다.

## 전체 흐름

```text
재료 하나를 push()
        ↓
덱 크기가 4 이상인가?
        ↓
앞의 네 값이 1, 3, 2, 1인가?
        ↓
일치하면 pop() 네 번
        ↓
햄버거 개수 증가
```

## 복잡도

각 재료를 한 번 넣고 매번 최대 네 개의 값만 확인하거나 제거한다.

- 시간 복잡도: `O(n)`
- 공간 복잡도: `O(n)`

반복자를 매번 생성하지만 최대 네 개만 확인하므로 전체 시간 복잡도는 `O(n²)`이 아니라 `O(n)`이다.
